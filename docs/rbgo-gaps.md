# rbgo gaps found while running Asciidoctor

Every divergence from MRI Ruby that asciidoctor-go works around, with a
minimal reproduction against rbgo v0.8.0 and where the workaround lives.
Expected results are MRI Ruby 3.4.10. These are candidates for upstream
reports; when rbgo fixes one, its workaround can be removed (each workaround
has a regression test in `internal/runtime`).

| # | Gap | Minimal reproduction (rbgo → MRI) | Workaround |
|---|---|---|---|
| 1 | No `cgi/escape` feature | `require 'cgi/escape'` → `LoadError` (MRI: loads) | `rubysrc/shims/cgi/escape.rb` requires `cgi` |
| 2 | `Gem.loaded_specs` undefined | `Gem.loaded_specs` → `NoMethodError` | prelude defines it |
| 3 | `StringScanner#get_byte` undefined | `StringScanner.new('a').get_byte` → `NoMethodError` | prelude adds it |
| 4 | `StringScanner` cannot match from inside a character | `s = StringScanner.new '¦x'; s.pos = 1; s.scan(/[^,]+/)` → `nil` (MRI: `"\xA6x"`) | `get_byte` scans a multibyte character whole |
| 5 | `File#mtime`, `#atime`, `#ctime` undefined | `File.open(f).mtime` → `NoMethodError` | prelude delegates to `File#stat` |
| 6 | `Module#===` ignores modules added with `extend` | `m = Module.new; m === ''.dup.extend(m)` → `false` (MRI: `true`; `is_a?` is correct) | prelude gives extended modules a correct `===` |
| 7 | `redo` keyword unsupported | `i = 0; while true; i += 1; redo if i < 2; break; end` → `NameError: undefined local variable or method 'redo'` | source patch (`internal/runtime/patch.go`) |
| 8 | Escapes in character literals mis-parsed | `?\u007f` → `"u"`; `?\x41` → `"\u0000"`; `?\C-a` → `"C"` (MRI: `"\u007F"`, `"A"`, `"\u0001"`) | source patches to double-quoted strings |
| 9 | Native `Logger` cannot be subclassed | `require 'logger'; class L < Logger; end; L.new(nil).class` → `Logger` (MRI: `L`); `Logger.allocate` + `initialize` fails | `rubysrc/shims/logger.rb` replaces it |
| 10 | Native `Rouge` lacks the gem's API | `Rouge::Lexer.find('ruby').new` → `NoMethodError` | reported as not installed (prelude) |
| 11 | Native libraries shadow `$LOAD_PATH` | a `logger.rb` earlier on `$LOAD_PATH` is ignored by `require 'logger'` | prelude intercepts `require` for replaced libraries |
| 12 | Native libraries' constants are predefined | `defined?(::Rouge)` → `"constant"` before any `require` | prelude removes replaced constants |
| 13 | `private_constant` still listed by `constants` | `module M; X = 1; private_constant :X; end; M.constants` → `[:X]` (MRI: `[]`) | avoided in shims |
| 14 | `TracePoint.new(:raise)` never fires | block is not called when an exception is raised | none needed (debugging aid only) |
| 15 | Parser accepts a command call in a rescue modifier | `x = 1 rescue p $!` parses (MRI: `SyntaxError`) | none needed |
| 16 | `NotImplementedError` inherits from `StandardError` | `NotImplementedError.superclass` → `StandardError` (MRI: `ScriptError`), so `rescue => e` catches it | prelude redefines it under `ScriptError` |
| 17 | `Class.new(superclass)` does not call `inherited`; `Class#inherited` is undefined | `b = Class.new; def b.inherited(s) = (p s); Class.new(b)` prints nothing (MRI: the subclass) | prelude defines the hook and calls it from `Class.new` |
| 18 | `super` resolution is wrong when the receiver is a class: a class method does not reach instance methods of `Class`/`Module`, and a method of a module extended into a class (or included in its singleton class) does not reach the next module | `class Class; def foo = 1; end; class X; def self.foo = super; end; X.foo` → `NoMethodError`; `module A; def m = :a; end; module B; include A; def m = super; end; class K; extend B; end; K.m` → `NoMethodError` (MRI: `1`, `:a`). Cause: `superMethod` (internal/vm/vm.go) searches from `classOf(self)` instead of the class's metaclass | source patch for the one such call in Asciidoctor (`MacroProcessorDsl#resolve_attributes`); the test harness avoids it. Ruby extensions that rely on it remain affected until rbgo is fixed |
| 19 | `Exception#full_message` omits the cause chain | a `rescue`-and-reraise shows only the outer exception (MRI also prints each cause and its backtrace) | prelude appends causes |
| 20 | A capitalized method call followed by a space and `::` parses as a scoped constant | `Integer ::ENV['X']` → `NameError: uninitialized constant Integer::ENV` (MRI: calls `Kernel#Integer`) | source patch (`document.rb`) |
| 21 | Standard library gaps | `FileUtils.rmdir`, `Kernel#Pathname`, `open-uri`, `Socket.ip_address_list`, `TCPServer#accept_nonblock` are undefined; `IO.select` rejects sockets | prelude: `FileUtils.rmdir`, `Pathname()`; `shims/open-uri.rb` (HTTP/HTTPS on `Net::HTTP`); test harness: `Socket.ip_address_list` |
| 22 | `Thread#exit` does not interrupt a thread blocked in `TCPServer#accept` | `t = Thread.new { server.accept }; t.exit; t.join` never returns (MRI: returns) | test harness: exiting an accepting thread closes its server first |
| 23 | String methods accept invalid byte sequences | on `"abc\xFF def  "` (UTF-8): `rstrip`/`strip` succeed (MRI: `Encoding::CompatibilityError`), `upcase`/`downcase`/`squeeze` succeed (MRI: `ArgumentError`), `reverse` replaces the bytes with U+FFFD (MRI: reverses them) | prelude: strict `rstrip`/`strip` (Asciidoctor's invalid-input detection) |
| 24 | `autoload` resolves paths natively, and an explicitly top-level reference does not trigger it | `autoload :OpenURI, 'open-uri'` ignores a `require` override; `autoload :X, 'x'; module M; def self.get = ::X; end; M.get` → `NameError` (bare `X` works) | prelude maps shimmed libraries in `Module#autoload`/`Kernel#autoload`, and satisfies Asciidoctor's top-level autoloads (`open-uri`, `pathname`, `strscan`, `uri`) immediately |
| 25 | URI objects are native and incomplete | `u = URI('http://x/a'); d = u.dup; d.host = 'y'; u.host` → `"y"` (MRI: `"x"`); `path=`, `query=`, `fragment=`, `user=`, `password=` undefined; `URI::HTTP.build(host: 'h', path: '/p').to_s` → `"//h/p"` (MRI: `"http://h/p"`) | source patch in `reader.rb` (`push_include`) using `AsciidoctorGoURI.with_path` |
| 26 | A backreference to a group that did not participate matches the empty string | `/(a)?\1b/ =~ "b"` → `0` (MRI/Onigmo: `nil`); conditional groups `(?(1)...)` are unsupported | source patches to `InlineLinkRx` and `InlinePassRx` (equivalent lookbehinds), verified against MRI |
| 27 | `$~` is one value per interpreter, not per method frame | `def m = ('q' =~ /q/); /(a)/ =~ 'a'; m; $1` → `nil` (MRI: `"a"`) | `shims/asciidoctor_go_frame_local_match.rb` wraps Asciidoctor's methods to restore the caller's `$~` |
| 28 | `module_function` mode outlives the module body | `module H; module_function; def f; end; end; H.send(:define_method, :g) {}; H.respond_to?(:g)` → `true` (MRI: `false`) | the frame-local wrapper ends the mode with `public` |
| 29 | `UnboundMethod#bind_call` rejects a subclass for a singleton method of its parent | `class P; def self.m = 1; end; class Q < P; end; P.singleton_class.instance_method(:m).bind_call(Q)` → `TypeError` (MRI: `1`) | the wrapper dispatches to per-class alias names instead |
| 30 | `OptionParser` rejects `nil` in argv and drops the value from `InvalidArgument` | `OptionParser.new.parse!([nil])` → `TypeError` (MRI: `[]`); `-d chapter` reports `invalid argument: -d` | prelude compacts argv and restores the value |
| 31 | go-ruby-haml emits `Haml::HamlAttributes.render(format, attrs)` while rbgo's helper takes one argument | a Haml template with dynamic attributes compiled with a format raises `ArgumentError` | the Tilt shim defines a format-aware `render` |
| 32 | `send`/`__send__` bind a trailing positional Hash as keywords | `def a(x = nil, k: 1) = x; send(:a, { 'm' => 1 })` → `ArgumentError: unknown keyword: "m"` (MRI: the Hash); a direct call is correct | the frame-local wrappers call the original directly |
| 33 | Lexical constant lookup in a class method misses the enclosing module when the class is declared with a compound path | `module O; K = 1; class C; end; class C::D; def self.m = K; end; end; O::C::D.m` → `NameError` (MRI: `1`); instance methods are correct | source patch (`manpage.rb`, the only such reference) |
| 34 | Opening a FIFO for reading holds the interpreter lock | `t = Thread.new { File.write fifo, 'x' }; File.read fifo` never returns (MRI: `"x"`) | none (the suite's named-pipe test is excluded) |
| 35 | Native `StringScanner` cannot be subclassed | `class S < StringScanner; def m = 1; end; S.new('a').class` → `StringScanner` (MRI: `S`); `S.allocate` has no scanner state and `initialize` takes no arguments | prelude gives subclasses an `initialize` that wraps a native scanner and forwards the scanner methods (needed by CodeRay) |
| 36 | A nested character class matches nothing | `Regexp.new('[a[bc]]+').match('abc')` → `nil`; also `[[[:alpha:]]_]` and intersections such as `[a-z&&[^aeiou]]` (MRI: `"abc"`, ...) | source patches flatten the classes in CodeRay's Java, Ruby and PHP scanners |
| 37 | `StringScanner` mis-reads octal escapes in a character class | `StringScanner.new('m').scan(/(?:[a-z]\|[^\0-\177])/)` → `nil` (MRI: `"m"`; `Regexp#match` is correct, and `\x00-\x7f` works) | the CodeRay patches use hex escapes |
| 38 | `Hash#dup` and `#clone` drop the default value and default proc | `Hash.new(5).dup[:x]` → `nil`; `Hash.new {\|_, k\| k }.dup[:y]` → `nil` (MRI: `5`, `:y`) | prelude copies them |
| 39 | `dup` and `clone` of an instance of a `Hash`, `Array` or `String` subclass lose the native storage | `class H < Hash; end; H.new.dup['a'] = 1` → `ArgumentError: []=: interface conversion: object.Value is *vm.RObject, not *object.Hash` | prelude copies `Hash` and `Array` subclasses through `allocate` and `replace`; `String` subclasses remain affected (`allocate` gives no storage either, and neither Asciidoctor nor CodeRay copies one) |
| 40 | `StringScanner` lacks `rest?`, `restsize`, `exist?`, `search_full`, `scan_full`, `peep`, `getbyte`, `peek_byte` (and `captures`, `named_captures`, `size`, `values_at`, `scan_byte`, `scan_integer`, `fixed_anchor?`) | `StringScanner.new('a').rest?` → `NoMethodError` (MRI: `true`) | prelude defines the first group from the methods rbgo has (CodeRay's Clojure scanner uses `rest?`); the others need the last match, which rbgo does not expose |
| 41 | The "interface conversion" errors of native methods escape `rescue` | `(class H < Hash; end; H.new.dup['a'] = 1) rescue :caught` raises instead of returning `:caught` | none (the cause, gap 39, is worked around) |
